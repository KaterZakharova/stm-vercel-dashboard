# STM dashboard

Локальная статическая версия дашборда СТМ для публикации на Vercel.

## Как обновлять сайт

1. Обновить исходные данные в локальной папке `_codex_excel_preview`.
2. Пересобрать дашборд скриптом `build_stm_html_dashboard.ps1`.
3. Скопировать свежий `stm_dashboard_preview.html` в этот проект как `index.html`.
4. Задеплоить проект на Vercel.

В этой версии данные уже встроены внутрь `index.html`. Следующий шаг для продакшена - вынести данные в отдельный `JSON`, чтобы сайт обновлялся без ручного редеплоя HTML.
